Privacy Policy

Rally Sync Tool is a browser-based tool designed to help organise and synchronise rally groups and players.

The information you enter into Rally Sync Tool, such as player names, group names and timings, is processed within your web browser.

Rally Sync Tool does not require an account and does not intentionally collect or transmit the information entered into the tool to the developer.

The tool does not intentionally collect personal information.

This website is hosted using GitHub Pages. GitHub may process technical information relating to visits to the website in accordance with GitHub's own policies.
